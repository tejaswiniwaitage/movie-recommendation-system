# 🎬 Movie Recommendation System

A Machine Learning based Movie Recommendation System built using Python and Streamlit.  
This project suggests movies similar to the selected movie using content-based filtering and cosine similarity.

---

## 📌 Features

- 🎯 Recommend movies based on selected movie
- 🧠 Content-based filtering using NLP techniques
- 📊 Cosine similarity for finding similar movies
- 🌐 Simple and interactive Streamlit web app
- ⚡ Fast and lightweight recommendation engine

---

## 🛠️ Technologies Used

- Python 🐍
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle

---

## 📂 Dataset

- TMDB 5000 Movies Dataset
- TMDB 5000 Credits Dataset

---

## ⚙️ How It Works

1. Data preprocessing (movies + credits merged)
2. Feature extraction (genres, keywords, cast, crew, overview)
3. Text vectorization using CountVectorizer
4. Cosine similarity calculation
5. Recommendation based on similarity score
